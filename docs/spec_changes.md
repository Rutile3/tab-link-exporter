# 仕様変更履歴

## 1.3.13

- 必須のDOM要素を取得する `getRequiredElement` 関数を追加しました。
- DOM要素が存在しない場合は、不足しているセレクターを含むエラーを投げ、初期化を停止するようにしました。
- 正常にDOM要素を取得できる場合の拡張機能の動作は変更していません。

## 1.3.12

- タブ取得後のステータスメッセージを三項演算子で選択し、`setStatus`を1回だけ呼び出す構造へ整理しました。
- 表示するメッセージとタブ取得時の動作は変更していません。

## 1.3.11

- `execCommand`を使用するコピーのフォールバック処理を、`copyWithExecCommand`関数へ分離しました。
- Clipboard APIを優先する処理、フォールバック条件、コピー結果の表示は変更していません。

## 1.3.10

- 画面設定の構造をJSDocの `Settings` 型として定義しました。
- UIから設定値を生成する処理を `getCurrentSettings` 関数へ分離し、`saveSettings`はその結果を保存する構造へ変更しました。
- 保存済み設定の項目別検証と拡張機能の動作は変更していません。

## 1.3.9

- `popup.js`の関数へ、目的、引数、戻り値を示す日本語のJSDocコメントを追加しました。
- タブ情報の構造をJSDocの型定義として明記しました。拡張機能の動作は変更していません。

## 1.3.8

- 出力形式の変更時に実行する処理を、名前付きの `handleFormatChange` 関数へ分離しました。
- 設定の保存、出力の再描画、ステータス表示の処理内容と実行順序は変更していません。

## 1.3.7

- `normalizeTabs`が「Webページのみ」の設定値を引数で受け取るようにし、UI要素への直接依存を解消しました。
- タブの絞り込み、並び順、出力内容は変更していません。

## 1.3.6

- イベントリスナーの登録と起動時処理を `initialize` 関数へ集約しました。
- 初期化時の処理順序と拡張機能の動作は変更していません。

## 1.3.5

- `formatTabs`内の分岐順を、画面上の出力形式の選択順に合わせました。
- 未知の出力形式が指定された場合は、「URLのみ」形式で出力するように変更しました。

## 1.3.4

- 出力仕様を変更せず、URL、タイトルとURL、Markdown、Scrapbox、CSV、JSONの整形処理をそれぞれ独立した関数へ分離しました。
- 出力形式の振り分けは、従来どおり `switch` 文で行います。

## 1.1.1

- 出力形式の選択肢を「URLのみ」「タイトル + URL」「Markdown」「CSV」「JSON」の順に変更しました。

## 1.1.0

- ファイル保存機能を廃止しました。
- 整形したタブ一覧の出力方法をクリップボードへのコピーのみに変更しました。
