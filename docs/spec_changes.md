# 仕様変更履歴

## 1.3.5

- `formatTabs`内の分岐順を、画面上の出力形式の選択順に合わせました。
- 未知の出力形式が指定された場合は、「URLのみ」形式で出力するように変更しました。

## 1.3.4

- 出力仕様を変更せず、URL、タイトルとURL、Markdown、Scrapbox、CSV、JSONの整形処理をそれぞれ独立した関数へ分離しました。
- 出力形式の振り分けは、従来どおり `switch` 文で行います。

## 1.1.1

- 出力形式の選択肢を「URLのみ」「タイトル + URL」「Markdown」「CSV」「JSON」の順に変更しました。

## 1.1.0

- ファイル保存機能を廃止しました。
- 整形したタブ一覧の出力方法をクリップボードへのコピーのみに変更しました。
