# 追加仕様履歴

## 1.3.14

- Node.js標準のテスト機能を使用した `tests/popup.test.js` を追加しました。
- 出力形式、タブ情報の正規化、設定、必須DOM要素、タブ取得、コピー処理を自動テストします。
- テストは配布用ZIPへ含めず、外部パッケージにも依存しません。

## 1.3.2

- Chrome Web Storeに掲載するアイコン、スクリーンショット、プロモーションタイルを `store-assets/` に追加しました。
- スクリーンショットとプロモーションタイルをChrome Web Storeの画像要件に合わせて作成しました。
- リポジトリ直下に `PRIVACY.md` を追加し、タブ情報、ローカル設定、外部リンクの取り扱いとLimited Use要件への準拠を明記しました。
- READMEにChrome Web Store用アセットとプライバシーポリシーの説明を追加しました。

## 1.3.1

- PowerShellで配布用ZIPを生成する `scripts/build-package.ps1` を追加しました。
- Manifestのバージョン番号を配布用ZIPのファイル名へ自動的に反映します。
- 配布対象を必要なファイルだけに限定し、生成後にZIPの内容と `manifest.json` の配置を検証します。
- 生成した配布用ZIPはGitの監視対象外である `dist/` に出力します。

## 1.3.0

- ポップアップ下部にフィードバック用Googleフォームへのリンクを追加しました。
- ポップアップ下部にOFUSEページへのリンクを追加しました。
- 外部リンクは新しいタブで開きます。

## 1.2.0

- 出力形式にScrapboxを追加しました。
