# 追加仕様履歴

## 1.3.1

- PowerShellで配布用ZIPを生成する `scripts/build-package.ps1` を追加しました。
- Manifestのバージョン番号を配布用ZIPのファイル名へ自動的に反映します。
- 配布対象を必要なファイルだけに限定し、生成後にZIPの内容と `manifest.json` の配置を検証します。
- 生成した配布用ZIPはGitの監視対象外である `dist/` に出力します。

## 1.3.0

- ポップアップ下部にフィードバック用Googleフォームへのリンクを追加しました。
- ポップアップ下部にOFUSEページへのリンクを追加しました。
- 外部リンクは新しいタブで開きます。

## 1.2.0

- 出力形式にScrapboxを追加しました。
- Scrapbox形式では、タブごとに `[URL タイトル]` の記法で1行ずつ出力します。
