# カスタム出力形式 実装TODO

## 目的

ユーザーが1タブ分のテンプレートを指定し、取得したタブを任意の文字列形式で一覧化できるようにします。

初回実装では機能を理解しやすく保つため、次の範囲をMVPとします。

- 出力形式に「カスタム」を追加する
- カスタム選択時だけテンプレート入力欄を表示する
- 1タブ分のテンプレートを各タブへ適用する
- 複数タブの出力は改行で連結する
- テンプレートをブラウザ内の `localStorage` へ保存する
- テンプレートは文字列置換だけで処理し、コードとして実行しない
- 既存の6種類の出力形式と既存設定の動作を維持する

## MVPの仕様

### プレースホルダー

| プレースホルダー | 置換する値     |
| ---------------- | -------------- |
| `{{title}}`      | タブのタイトル |
| `{{url}}`        | タブのURL      |

### 置換規則

- 同じプレースホルダーを複数回使用できる
- テンプレート内の改行を維持する
- 未知のプレースホルダーは置換せず、そのまま出力する
- タイトルやURLなどの値は、そのまま文字列として埋め込む
- Markdown、CSV、JSONなどに固有のエスケープ処理は行わない
- `eval`、`new Function`、`innerHTML`は使用しない
- 出力結果は従来どおり読み取り専用テキストエリアの `value` へ設定する

### 既定値と空のテンプレート

カスタムテンプレートの初期値は、次の文字列とします。

```text
{{title}}
{{url}}
```

既存の保存設定にカスタムテンプレートが存在しない場合も、この初期値を使用します。

ユーザーがテンプレートを空にした場合は、既定値へ自動的に戻さず、空の出力を生成します。入力途中の内容を意図せず置き換えないためです。空の出力はコピー対象がない状態として扱います。

### テストケース

カスタム整形処理では、少なくとも次のケースを自動テストします。

| ケース                  | 期待結果                                      |
| ----------------------- | --------------------------------------------- |
| `{{title}}`             | タブのタイトルへ置換される                    |
| `{{url}}`               | タブのURLへ置換される                         |
| `{{title}} - {{title}}` | 同じ値が2回出力される                         |
| 複数行のテンプレート    | テンプレート内の改行が維持される              |
| 複数タブ                | 1タブ分の出力が改行で連結される               |
| `{{unknown}}`           | 未知のプレースホルダーがそのまま残る          |
| 空文字                  | 空の出力になる                                |
| Markdown風テンプレート  | タイトルとURLがエスケープされず、そのまま入る |

既存機能の回帰確認として、URL、タイトルとURL、Markdown、Scrapbox、CSV、JSONの出力結果も引き続きテストします。
